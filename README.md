# Szkoła Barberingu Old Town — landing page

Landing page for the barbering school run by Barber Shop Old Town, Tarnowskie Góry.

## Project phases

1. **Product requirements** — `docs/prd.md` (what, why, scope, open questions for the owner)
2. **Creative direction** — `docs/creative-direction.md` (identity, layout, imagery, copy rules)
3. **Technical solution** — `docs/technical-solution.md` (stack, hosting, form backend, analytics, content files)

## Source material

- `texts.txt` — original copy written by the owner (manifesto and two course descriptions), in Polish.
- `docs/sources/` — the owner's answers to project questions, verbatim, with a mapping to the PRD.
- `docs/prompts/` — reusable prompts for design exploration and later phases.
- `How to turn your AI into a world-class designer.pdf` — the design-process article the prompts follow (seed strings, specific anchors, critic subagent, restraint).

## Conventions

- Page content is Polish. Code, identifiers, commit messages and docs are English.
- Content that changes (courses, prices, dates, FAQ, team) lives in structured files, not in markup.
